# SKY ACE — REBIRTH

세로 스크롤 탄막 슈팅 게임. 자동 사격, 무기 강화, 보스전, 방향성 화면 진동, 충격파와 시네마틱 쇼케이스를 제공합니다.

## 실행

`dist/index.html`을 브라우저에서 열거나, Node.js가 설치된 PC에서 `node preview.cjs`를 실행하고 http://127.0.0.1:4173 에 접속합니다.

## 조작

- WASD / 방향키 / 터치 드래그: 이동
- Shift: 무적 대시
- Space: 노바 폭탄
- P: 일시정지
- FX MAX / MID / LOW: 연출 강도
- 시네마틱 쇼케이스: 자동 비행으로 연출 감상

## Netlify

이 저장소를 Netlify에 연결하세요. `netlify.toml`에 배포 폴더 `dist`가 설정되어 있습니다. 빌드 명령과 패키지 설치는 필요 없습니다. Netlify 배포 URL을 휴대폰 브라우저에서 열면 플레이할 수 있습니다.

이미지는 `dist/assets`에 포함되어 있습니다. 생성 기록은 `ASSETS.md`를 참고하세요. Google Fonts에 연결되지 않는 환경에서는 시스템 대체 폰트를 사용합니다.
